# **App Name**: GATE Ready Reckoner

## Core Features:

- Personalized Study Plan Generation: Generates a personalized study plan tailored to the student's target GATE year and start date, using an AI tool to decide the optimal schedule, resources to incorporate and pace based on generic exam-preparation guidelines.
- Curated Resource Library: Provides access to a comprehensive library of study resources, including past year question papers, YouTube playlist links, and downloadable PDFs.
- Timed Test Engine: Offers a timed test engine for students to attempt curated practice tests.
- Performance Analytics: Stores test results and provides detailed analytics, including topic-wise accuracy and score trends.
- Progress Tracker: Allows students to track their syllabus completion percentage and logged study hours.
- User Authentication: Implements secure user sign-up and login functionality using email and Google authentication.
- Profile Creation: Enables students to create and manage their profiles, including name, branch, target GATE year, and start date.

## Style Guidelines:

- Primary color: Saturated blue (#3F51B5) to convey trust and intelligence, referencing academic settings but avoiding clichés.
- Background color: Light gray (#F0F2F5), of similar hue to the blue, for a clean and focused learning environment.
- Accent color: Orange (#FF9800), analogous to blue, to highlight key actions and CTAs, providing a motivational spark.
- Headline font: 'Space Grotesk' sans-serif for a techy feel; body text: 'Inter' sans-serif to ensure readability for long study sessions. 'Space Grotesk' is well suited for the titles but it is best to use 'Inter' when longer text is needed.
- Use clear, consistent icons for navigation and resource categorization, with a focus on legibility and ease of understanding.
- Prioritize a clean and intuitive layout, ensuring easy access to key features and minimizing distractions.
- Incorporate subtle animations for feedback and progress indicators to enhance user engagement without overwhelming the interface.
